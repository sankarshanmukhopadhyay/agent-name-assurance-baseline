# ANAB v0.9.0 release notes

## Release title

ANAB v0.9.0 — TIS v0.9 Agent Runtime Trust Artifact Synchronization

## Summary

This release synchronizes ANAB with `trust-infrastructure-schemas` v0.9.0 and its DTG/OpenVTC/VTI runtime trust artifact profiles. The release adds a named-agent interpretation layer for TIS-backed evidence while preserving ANAB control IDs, declaration semantics, and domain-baseline scope.

## What changed

- Added a TIS v0.9 agent-name composition profile.
- Added a TIS-backed enterprise agent declaration sample.
- Added a machine-readable TIS compatibility review manifest.
- Added TIS/DCAS/ANAB alignment and known-good stack documentation.
- Refreshed README, docs index, architecture, ecosystem interoperability, runtime lifecycle, A2A binding, roadmap, changelog, and version metadata.
- Extended validation to check the new TIS-backed sample and local compatibility manifest.

## Why it matters

Named agents increasingly rely on runtime trust infrastructure for credential evidence, relationship state, authorization, routing, provision, and decision evidence. ANAB now explains how those artifacts should support agent-name assurance without over-claiming them as proof of name assurance.

## Compatibility

This is an additive release. Existing ANAB declaration samples, evidence bundle samples, A2A extension samples, and OASF publication samples remain valid.
