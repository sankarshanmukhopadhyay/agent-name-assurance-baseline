# Support

Use GitHub Issues for reproducible defects, documentation problems, assurance-model questions, and bounded change proposals. Include the affected version/revision, expected and observed behaviour, and links to relevant evidence or fixtures.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be disclosed publicly before remediation.

ANAB owns named-agent assurance requirements and evidence semantics. Downstream evaluator or interoperability questions should be routed to the repository that owns the relevant evaluation or execution surface when the question is outside ANAB's authority.
